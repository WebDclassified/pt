# Phase 02 — Creative Brief

## Creative title

# BUILD / BREAK / REBUILD

## Positioning

A cinematic interactive portfolio for software developer **Prabhat Teotia**.

## Experience promise

The visitor should feel like they entered an interactive short film — not a standard portfolio.

## Desired reactions

Recruiter:
> “I immediately understand what this person does and can inspect the evidence.”

Designer:
> “The art direction and motion system feel authored.”

Engineer:
> “I want to know how this was built.”

## Visual keywords

- cinematic industrial futurism
- premium CGI
- architectural scale
- technical precision
- editorial typography
- dark graphite environments
- restrained acid-lime signal color
- glass / metal / ceramic materials
- atmospheric light
- deliberate negative space
- mystery → discovery → tension → resolution

## Explicitly avoid

- generic cyberpunk
- galaxy/planet/space clichés
- generic astronaut/robot hero
- floating laptop cliché
- giant spinning sphere with no narrative
- purple/blue AI gradient cliché
- 3D room with desk-and-monitor cliché
- constant neon glow
- particle spam
- endless parallax for decoration
- copying Bruno Simon or any other portfolio
- copying exact scene concepts from inspiration sites

## Central metaphor

Software becomes physical architecture.

Ideas become structures.
Systems become environments.
Failures become fractures.
Fixes become reconstruction.
Projects become artifacts.
The full portfolio eventually reveals itself as one connected world.

## Signature object

**THE CORE**

A custom abstract object combining:

- architectural geometry
- translucent layers
- graphite/metal materials
- small signal nodes
- controlled emissive light
- data/system cues

It is not a planet, robot, or spaceship.

## Signature motifs

1. A point of light — idea/origin.
2. A thin line — connection.
3. A circular aperture — recurring transition.
4. The Core — identity/system.

## Signature color

Acid-lime signal color in a near-black/graphite environment with warm-white typography.

Do not use the accent as a general fill everywhere. It indicates active/important states.

## Gate

PASS only when the moodboard and first art-direction board demonstrate a coherent original visual language that is distinct from the previous portfolio.
