# Phase 03 — Screenplay and Story Structure

## Objective

Write the portfolio as a short interactive film before building scenes.

## Main narrative

**Idea → System → Work → Failure → Rebuild → Experiment → Human → Future**

## Major sequence

### 00 — PROLOGUE

Black screen.
Tiny point of light.

Text:

> EVERYTHING BEGINS WITH AN IDEA.

The point grows as the visitor scrolls.

### 01 — ARRIVAL

Large architectural void.
The Core is distant.
Atmosphere slowly appears.

### 02 — IDENTITY

Prabhat Teotia.
Software Developer / Full-Stack Developer positioning.
The Core responds to words like systems, interfaces, experience.

### 03 — ENTER THE SYSTEM

The Core opens.
Camera enters a physicalized software architecture.

### 04 — EXPERIENCE

A long architectural timeline.
Career/leadership milestones become environmental markers.

### 05 — PROJECT 01 / VIZQUO

The environment transforms into an inspection laboratory.
The project artifact demonstrates “surface → inspect → understand.”

### 06 — PROJECT 02 / QUPAY

Payment/wallet architecture becomes physical.
Auth, accounts, balances and transactions appear as system components.

### 07 — FAILURE / REBUILD

A controlled failure sequence explains one real engineering challenge from a verified project.
Only use a real challenge if the repository supports it.

### 08 — PROJECT 03 / HILO

Social graph / posts / interactions become a networked environment.

### 09 — PROJECT 04 / MEDIUM BLOG

A typographic publishing environment.
Content layers and relational data become architecture.

### 10 — PROJECT 05 / BLOCK SWAP

Blockchain/transaction-flow environment.
Keep the visual metaphor abstract, not “crypto neon.”

### 11 — SYSTEMS / ENGINEERING

Technical x-ray of how Prabhat approaches frontend, backend, data, APIs and authentication.

### 12 — LAB

Experimental creative technology section.
Potential experiments: GLSL, Three.js, WebGPU/TSL, particles, physics, data visualization, AI visualization.
Only include real experiments once built.

### 13 — ABOUT

Strong reduction in complexity.
Simple human scene, portrait if available, concise story.

### 14 — NOW

Current learning/building/exploring statements.
Only verified/current content.

### 15 — FINALE

Camera pulls far back and reveals the entire environment as one connected system.

Text:

> BUILD / BREAK / REBUILD

Then clear contact/resume/social actions.

## Emotional pacing

Use:

`mystery → reveal → scale → technical clarity → tension → silence → resolution → wonder → human warmth`

Never make every scene a climax.

## Gate

PASS only if the screenplay can be read without implementation jargon and still tells a coherent story.
