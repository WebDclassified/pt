# Phase 19 — Final Credits, Attribution, and Ownership

## Primary portfolio credit

The portfolio is the personal website and professional presentation of:

# Prabhat Teotia

The finished experience must make this visible.

## Authorship policy

Creative direction, portfolio content, personal identity, and portfolio ownership are credited to **Prabhat Teotia**.

Implementation contributors may be acknowledged separately if applicable.

## Third-party attribution

Maintain a `CREDITS.md` file containing:

- framework/library
- package/repository
- creator/organization
- license
- where used
- required attribution text

## Asset attribution

For every external asset, determine:

- source
- author
- license
- whether commercial/public portfolio use is allowed
- whether visible attribution is required

Never include an external 3D model, sound, image, font, or code snippet merely because it looks good.

## Inspiration policy

The websites and research used to inform this project are **inspiration/research references**, not authorship sources.

Do not copy:

- exact compositions
- exact animations
- exact copy
- exact assets
- exact interactions
- exact 3D environments

## Credits UI

The final portfolio may have a small “Credits / Tech” area, for example:

```text
A portfolio by Prabhat Teotia.
Built with React / Next.js / Three.js / React Three Fiber / GSAP,
with selected third-party tools and assets credited below.
```

Use actual technologies only if used in the production build.

## Vizquo credit

- **Project:** Vizquo
- **Creator/owner attribution:** Prabhat Teotia (only where repository/profile evidence supports this)
- **Repository/license/contributors:** according to the live repository metadata

## Final ownership check

Before launch, perform a full attribution audit and ensure the finished portfolio gives appropriate credit to Prabhat Teotia while accurately crediting every third-party component.

## Gate

PASS only when the credits file is complete and no external asset/library is presented as original Prabhat work.
