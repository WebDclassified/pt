# Phase 04 — Scene and Shot Design

## Objective

Turn the screenplay into storyboard-level shot specifications.

## Each shot must define

- scene ID
- narrative purpose
- dominant focal point
- camera position
- camera target
- depth layers
- primary object
- secondary objects
- lighting
- text
- interaction
- audio cue
- transition in
- transition out
- performance budget
- accessibility behavior

## Shot hierarchy

### Foreground

Emotional/immediate reference.

### Midground

Primary content and project artifacts.

### Background

Architecture/context.

### Atmosphere

Fog, dust, particles, light.

## Camera grammar

- wide establishing shot = context/scale
- push-in = discovery
- orbit = inspection
- tracking = journey
- pull-back = reveal/context
- lock-off = seriousness
- rapid move/whip = major energetic transition
- controlled tilt/roll = orientation change

## Film-frame test

For every major scroll state, capture a screenshot and ask:

> Would this still look intentional as a single film frame?

If not, fix the composition.

## Safe areas

Every shot must define protected zones for:

- navigation
- section title
- project metadata
- CTA

No lighting or geometry should destroy text legibility.

## Scene variety

Do not make every environment dark CGI.
Use tonal contrast:

- architectural realism
- abstract technical visualization
- typographic environment
- blueprint scene
- experimental GPU scene
- calm human scene

Keep the global language consistent through:

- typography
- materials
- accent
- camera behavior
- transition motifs

## Gate

PASS only if every major scene has a storyboard and a clear narrative reason to exist.
