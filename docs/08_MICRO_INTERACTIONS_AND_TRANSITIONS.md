# Phase 08 — Micro-Interactions and Transition Grammar

## Objective

Create one coherent motion language across DOM, 3D, and scene transitions.

## Global interaction states

Every interactive element should define, where relevant:

- rest
- hover
- focus
- pressed
- active
- exit

## Motion grammar

### ENTER

Fade/slide/clip reveal.

### ACTIVATE

Light + subtle scale/position response.

### CONNECT

A line grows or a system connection appears.

### TRANSFORM

Morph or reconfigure an object.

### ERROR

Controlled fracture/distortion.

### RECOVER

Reassembly/coherence.

### TRANSITION

Camera + aperture/mask/shader.

## Signature transition

Use a recurring **circular aperture** motif.

It can become:

- portal
- object
- mask
- database ring
- project framing device

It must recur without becoming repetitive.

## Transition families

Use several, chosen by narrative reason:

- physical occlusion
- camera traversal
- morph
- shader dissolve
- aperture wipe
- particle transformation
- light sweep
- match cut
- controlled whip movement

Do not use the same fade/zoom sequence everywhere.

## Continuity rules

Transitions should preserve at least one of:

- motion direction
- material
- lighting source
- shape
- sound
- spatial location

This creates perceptual continuity.

## Micro-interaction examples

Project hover:

- project title shifts slightly
- image/3D artifact scales ~1–2%
- signal line grows
- ambient light responds

Button:

- subtle physical response
- arrow movement
- signal accent

Do not use giant cursor effects or exaggerated magnetic movement.

## Typography motion

Hero/chapter titles may use character/word reveals.
Body copy should use simpler motion.

## Gate

PASS only if interactions feel deliberate and related to the site's narrative language rather than a collection of unrelated animation tricks.
