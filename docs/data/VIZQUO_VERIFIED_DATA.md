## Identity

**Vizquo** — an open-source browser extension / developer tool for inspecting how a webpage was built.

## Verified public description

Vizquo is described publicly as a tool that puts several web-inspection workflows into one place, including:

- inspect elements and computed CSS
- discover design-system information such as colors, type, spacing, and tokens
- extract images, SVGs, and fonts
- analyze responsive behavior and accessibility
- experiment with live CSS edits

A distinctive Vizquo concept is its confidence labeling:

- Detected (observed)
- Derived (calculated)
- Inferred (guessed)
- AI-generated

The project is positioned as:

- local-first
- core workflow works locally
- AI optional and consent-gated
- open source

The GitHub repository is publicly associated with **WebDclassified/vizquo** and described as a design-system inspection tool. A public repository listing identifies TypeScript and an MIT license; verify the live repository before publishing license details in production.
