## Definition of done

Done means:

- cinematic experience is coherent
- 3D is genuinely integrated into the story
- scene transitions are continuous and motivated
- micro-interactions share one motion grammar
- the experience has pauses/contrast, not constant motion
- recruiter can understand Prabhat quickly
- engineer can inspect technical depth
- designer sees a highly authored visual identity
- DOM content works without the 3D layer
- mobile is intentionally composed
- reduced motion is supported
- audio is optional
- WebGL failures have graceful fallback
- Core Web Vitals/performance targets are aggressively pursued
- no critical accessibility issues remain
- no critical security issues remain
- project claims are factual
- credits are correct
