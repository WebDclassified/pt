# Phase 00 — Agent Execution Protocol

## Mission

Build a world-class cinematic software-engineer portfolio for Prabhat Teotia. The agent is acting as creative director, UX architect, 3D technical director, motion designer, frontend engineer, accessibility engineer, performance engineer, QA engineer, and release engineer.

## Prime directive

The portfolio is **not** a generic website with 3D decoration. It is an interactive film whose underlying content is still a robust, crawlable, accessible portfolio.

The cinematic layer must enhance communication, not replace it.

## Mandatory loop for every phase

### A. Interpret

Before coding, state:

- exact phase objective
- inputs used
- constraints
- deliverables
- acceptance criteria

### B. Build

Implement only what the phase requires plus small support utilities that clearly enable it.

### C. Inspect

The agent must inspect the result using real browser rendering, not only source code.

Inspect at minimum:

- desktop wide viewport
- desktop standard viewport
- mobile viewport
- keyboard navigation
- reduced-motion mode
- low-performance fallback where relevant

### D. Compare

Create a deviation report with:

| Check | Required | Actual | Status | Fix |
|---|---|---|---|---|

Every requirement must be marked PASS or FAIL.

### E. Correct

Fix every FAIL that is technically possible within the phase.

### F. Re-test

Run the same checks again. Do not simply assume the fix worked.

### G. Gate

Proceed only when:

- no critical deviations remain
- no known broken interactions remain
- factual content is unchanged unless explicitly approved
- no fabricated metrics/claims were introduced
- the implementation is consistent with previous phase contracts

## Visual quality loop

For every major cinematic shot:

1. Evaluate composition as a still frame.
2. Evaluate the camera path as motion.
3. Evaluate transition from previous shot.
4. Evaluate transition into next shot.
5. Check typography legibility.
6. Check whether the 3D element communicates a concept or is merely decorative.
7. Check whether the scene has one dominant focal point.
8. Check pacing and visual breathing room.

If a shot looks impressive only because many effects are running simultaneously, simplify it.

## Content integrity rules

- Never invent employers, awards, users, metrics, technologies, responsibilities, testimonials, clients, education, dates, or outcomes.
- Never turn a public/social claim into a fact unless it is verified and captured in the source file.
- Never present illustrative/example metrics as real results.
- Never present generic AI-generated testimonials as real people.
- The six “Mentor Feedback / Peer Developer / Team Member / Project Reviewer / Training Coordinator / Peer Learner” entries from the previous portfolio are not trusted as verified testimonials and must not be published as testimonials unless separately verified.
- The previous portfolio's “Pluto” location line is clearly playful/fictional and must not be treated as a real location.

## Attribution rules

Visible credits must identify Prabhat Teotia as the portfolio owner/creator.

A small credits area must distinguish:

- Portfolio concept/direction: Prabhat Teotia
- Portfolio engineering: Prabhat Teotia / implementation team if applicable
- Third-party libraries/frameworks: their original authors/projects
- Licensed models/assets: original creators and license
- Music/SFX: original creators/license

Do not hide required license text.

## Stop conditions

Stop a phase and fix before continuing if:

- scene feels like a template clone
- 3D blocks critical content
- mobile becomes unusable
- scroll feels hijacked or physically uncomfortable
- interactive performance becomes unstable
- accessibility regressions are introduced
- factual data is changed without evidence
- old portfolio design is being copied rather than data being reused
