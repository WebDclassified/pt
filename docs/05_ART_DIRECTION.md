# Phase 05 — Pixel-Level Art Direction

## Objective

Establish the visual design system before mass implementation.

## Palette

Primary environment:

- near-black: approximately `#050607`
- graphite: approximately `#0B0E10`
- raised surface: approximately `#111518`
- warm white: approximately `#F1EFE8`
- secondary gray: approximately `#969B9F`
- signature signal: approximately `#C8FF3D`

These are starting tokens, not rigid exact values. Final values must be tuned against contrast and cinematic grading.

## Material language

- graphite
- blackened metal
- smoked glass
- frosted glass
- ceramic
- translucent acrylic
- controlled emissive strips

## Lighting

Use lighting to create narrative progression:

- prologue: almost dark
- discovery: light increases
- problem: fragmented/unstable light
- solution: coherent lighting
- lab: experimental lighting
- about: soft neutral light
- finale: broad reveal

## Typography

Use three roles:

### Display

Premium contemporary grotesk/editorial face.

### Body

Highly readable neutral sans.

### Technical

Monospace for metadata and systems.

Do not use huge display type for every piece of copy.

## Type hierarchy

- hero statement: very large
- chapter title: large
- project name: large
- supporting copy: readable
- metadata: compact mono

## Grid

Desktop baseline: 12 columns.
Tablet: 8.
Mobile: 4.

Allow deliberate grid-breaking for cinematic shots.

## Spacing

Use a coherent spacing scale based around small multiples such as:

`4, 8, 12, 16, 24, 32, 48, 64, 96, 128, 160`

Adjust to the font/layout system rather than treating these as law.

## Border/line language

Use thin rules and lines to communicate systems and chapter boundaries.

## UI shapes

Buttons and controls should be restrained and tactile.

Avoid generic glassmorphism cards everywhere.

## Gate

PASS only after visual tokens are implemented and checked in representative desktop/mobile scenes for hierarchy, readability, contrast, and consistency.
