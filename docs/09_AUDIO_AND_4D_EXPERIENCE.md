# Phase 09 — Audio and IMAX/4D-Inspired Sensory Layer

## Objective

Create the perception of physicality through coordinated visual, auditory, and input responses.

## Four channels

1. visual
2. audio
3. interaction
4. optional device/haptic enhancement

## Audio defaults

Audio must be OFF by default or enabled only after explicit user interaction.

Provide an always-available sound control.

## Audio layers

- ambience
- interaction/UI
- transition
- music
- environmental accents

## Scene-specific acoustic identity

Example:

- main world → spacious ambience
- systems room → precise/dry
- failure → tension/low-frequency texture
- lab → electronic/experimental
- about → nearly silent
- finale → open/airy

## Scroll/audio coupling

Optional coupling:

- velocity → intensity
- scene → acoustic identity
- transition → crossfade/lowpass shift

Never allow audio processing to become more important than content.

## No autoplay abuse

Browser autoplay restrictions must be respected.
Request microphone, camera, motion sensor, or other permissions only after explicit user intent and only when a real experiment needs them.

## Haptics

Optional progressive enhancement only. Do not require device vibration APIs.

## Reduced motion

Reduced-motion mode should remove major camera movement and nonessential continuous motion while retaining the information architecture.

## Gate

PASS only if the site still works fully with audio OFF and without device-specific sensors.
